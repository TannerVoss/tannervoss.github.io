Android foreground monitoring demonstration

Recorded on a physical Samsung phone on October 27, 2026 using the internal test build. The footage shows the background-monitoring option enabled, a dashboard reporting a Wi-Fi connection, the persistent monitoring notification while outside the app, and monitoring disabled.

This is an edited sequence from separate takes. The notification segment is cropped to remove unrelated personal phone content. It does not demonstrate every smoker command, temperature accuracy, alert delivery, or long-term background reliability.

Package submitted to Google Play: com.pitvoss.app. The internal test variant uses com.pitvoss.app.internal with test ads; it shares the release monitoring implementation.
